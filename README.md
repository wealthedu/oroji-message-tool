# 오로지교육 · 고객 관리 메시지 툴

FC(설계사)가 상황별 고객 접촉 문자를 빠르게 찾아 카카오톡으로 보내거나 복사할 수 있는 단일 페이지 웹 도구입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 메인 앱. 카테고리별 멘트 카드 · 검색 · 즐겨찾기 · 이미지 카드 생성/전송. **단일 파일로 완결**(로고 base64 내장, 외부 의존성 없음). |
| `message-templates.html` | 메시지 템플릿 모음 |
| `logo-white.png` | 로고 원본 이미지 |

## 사용 방법

- **바로 열기**: `index.html`을 브라우저로 열면 그대로 동작합니다.
- **아임웹 삽입**: `index.html` 내용을 아임웹 `[코드 삽입]` 블록에 붙여넣어 사용합니다.
- **링크 공유**: 정적 호스팅(GitHub Pages / Netlify 등)에 `index.html`을 올리면 링크로 공유됩니다.

## 여러 PC에서 작업하기

```bash
# 새 PC에서 최초 1회
git clone <이 저장소 주소>
cd 오로지교육_고객_관리_메세지_툴

# 작업 후 저장
git add -A
git commit -m "수정 내용"
git push

# 다른 PC에서 최신 내용 받기
git pull
```
