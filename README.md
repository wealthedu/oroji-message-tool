# 오로지교육 · 고객 관리 메시지 툴

FC(설계사)가 상황별 고객 접촉 문자를 빠르게 찾아 카카오톡으로 보내거나 복사할 수 있는 단일 페이지 웹 도구입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 메인 앱. 카테고리별 멘트 카드 · 검색 · 즐겨찾기 · 카톡 텍스트 전송/복사. **단일 파일로 완결**(로고 base64 내장). |
| `message-templates.html` | 메시지 템플릿 모음 |
| `logo-white.png` | 로고 원본 이미지 |

## 사용 방법

- **바로 열기**: `index.html`을 브라우저로 열면 동작합니다. 단, 카톡 친구 선택창은 뜨지 않고 공유시트/복사로 폴백합니다(아래 참고).
- **아임웹 삽입**: `index.html` 내용을 아임웹 `[코드 삽입]` 블록에 붙여넣어 사용합니다.
- **링크 공유**: 정적 호스팅(Netlify 등)에 `index.html`을 올리면 링크로 공유됩니다.

## 카톡 친구 선택창 전송 설정

[카톡으로 보내기]를 누르면 카톡 친구 선택창이 열리고, 링크·버튼 없는 **순수 텍스트 말풍선**이 전송됩니다.
이 기능은 **카카오에 등록된 https 도메인에서만** 동작합니다. `file://`로 열면 카카오가 거부합니다.

1. Netlify 등에 배포해 `https://<이름>.netlify.app` 확보
2. [카카오 개발자센터](https://developers.kakao.com) > 내 앱 > 플랫폼 > **Web** > 사이트 도메인에 그 origin을 등록
   (로컬 확인용으로 `http://localhost:5500`도 함께 등록)
3. `index.html`의 `ALLOWED_HOSTS` 배열에 배포 host를 적어 넣기

> `ALLOWED_HOSTS`에 없는 host에서는 친구 선택창을 시도하지 않고 조용히 공유시트/복사로 폴백합니다.
> 도메인을 옮기거나 아임웹에 삽입할 때는 이 배열과 카카오 등록 도메인을 함께 갱신하세요.

**제약**: 카카오 텍스트 템플릿은 본문 **200자**까지입니다. 초과하면 전송이 막히고 자동으로 복사됩니다.

로컬 확인:

```bash
python3 -m http.server 5500   # 이후 http://localhost:5500 접속
```
